# GRAVITAS × ATELIER 3D

Pure client-side 3D spatial interactive web experiences ready for GitHub Pages deployment.

## Included Applications

1. **GRAVITAS** (`/cosmos-gravity/`)
   - Real-time 3D relativistic spacetime gravity field & particle orbital engine
   - Supports 5 selectable audio sources: off, internal procedural synthesizer, system/tab audio capture, external microphone, and local audio file
   - Supports Dark / Light polarity inversion and zero-gravity glide

2. **ATELIER 3D** (`/spatial-studio/`)
   - Real-time 3D spatial light-painting & mathematical manifold studio
   - 5 volumetric optical brushes with multi-layer luminescent filament cores
   - Quick camera orbit via `Command`/`Ctrl`/`Alt`/`Space` + drag
   - 3D curved synaptic Star-Web interconnection (`星网互联`)
   - 3D mathematical equation plotter (`z = f(x, y)`, `y = f(x)`, `r = f(t)`, parametric curves)
   - Transparent PNG artwork export

3. **Portal & Showcase Reel** (`/index.html`, `/gravitas-atelier-intro.mp4`)
   - Unified landing portal linking to both `/cosmos-gravity/` and `/spatial-studio/` alongside the 1080p showcase trailer.
